# My Website 

This is a simple multi-page HTML website project created for learning purposes.

## Project Structure

my-website/
│
├── index.html
├── about.html
├── gallery.html
├── lists.html
├── table.html
├── form.html
│
└── images/
    ├── profile.jpg
    ├── banner.jpg
    ├── gallery1.jpg
    ├── gallery2.jpg
    └── gallery3.jpg

##  Features

- Multiple HTML pages
- Navigation between pages
- Images with correct paths
- Lists (ordered & unordered)
- Tables
- Form with different input types
- Anchor links (jump within page)

##  Purpose

This project is part of learning HTML basics, including structure, links, images, forms, and tables.
